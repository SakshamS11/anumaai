# Optional external enrichment

ANUMA's MVP core produces interaction intelligence from conversation, speaker evidence, deterministic interaction metrics, structured facts, client-defined expectations, and human corrections. It does not require an external business system.

Future optional enrichment may connect a product catalogue, CRM, POS, inventory, pricing, promotions, ERP, DMS, ticketing, or other authoritative operational source. Those sources may add context but never replace evidence-extracted conversation claims or become a prerequisite for core interaction understanding.

The previous product-catalogue experiment was intentionally deferred before its migration was applied to an authoritative environment. Its design remains available in Git history; it is not active MVP functionality.
